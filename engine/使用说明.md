# 精读报告使用说明

## 打开报告
- **推荐**：在浏览器打开精读主页 **http://127.0.0.1:8614/**（端口以安装时为准），按文件夹列出所有精读报告，可以按标题、会议、标签、状态筛选。
  - 收藏成书签；或者做成独立 App：Chrome / Edge 菜单「安装此页面为应用」，Safari「文件 → 添加到程序坞」。
- 直接**双击报告的 .html** 也可以：如果你还没在这份报告上直接记过笔记，页面会自动跳到精读主页打开。
- 从主页打开时，笔记、高亮、图片**自动存成文件**，清除浏览器数据也不受影响。
- 主页没打开？对助手说"启动精读主页"，或运行 `engine/hubctl.py start`（用 `engine/.venv` 里的 Python）。

## 读的时候
| 操作 | 方法 |
|---|---|
| 高亮 | 选中文字 → 黄 = 重点、绿 = 懂了、粉 = 疑问（会进疑问清单）、蓝 = 概念 |
| 批注 | 选中文字 → 💬 批注；点已有的高亮可以改颜色、写批注、删除 |
| 小节笔记 | 每节末尾「写笔记」，或按 `c` 打开右侧笔记面板；行首 `??` 记疑问，`!!` 记重点 |
| 标记 | 笔记面板里：⭐ 重点 ❓ 没懂 💡 想法 🔗 可借鉴；读懂了点「✓ 读懂了」 |
| 原文对照 | 点出处标签（如 p.3）→ 打开原文 PDF 的对应页（用 Zotero 时在 Zotero 里打开） |
| 自测 | 答案默认遮住，点一下显示 |
| 汇总 | `s` 打开笔记汇总，可以只看疑问、重点、想法、可借鉴、未读懂 |
| 跳转 | `j` / `k` 下一节 / 上一节，`/` 搜索，`t` 收起目录 |

想让助手答疑时，直接说"看一下 XX 论文的疑问"，助手会读 `data/<论文ID>/notes/summary.md`。

## 文件放在哪
```
<数据根目录>/
├── _paper-reading/
│   ├── engine/            后台服务和构建工具（由 paper-reading skill 安装，可随时重装）
│   └── data/<论文ID>/      原文 source.pdf、讲解源文件、截图、交互演示，以及 notes/（你的笔记）
└── reports/…/<报告>.html   每篇论文只有这一个文件
```
- 笔记在 `data/<论文ID>/notes/`：`data.json` 每次覆盖更新；`backup/` 每天一份、保留 30 天；`summary.md` 是可读版本。
- 报告可以移动、重命名（改完告诉助手更新 `paper.json` 的 `out` 并重新构建）；笔记按论文 ID 保存，不会丢。
- 报告是单个文件，图片和公式都在里面，可以直接发给别人看（别人看不到你的笔记，页码链接也只在你的电脑上能打开原文）。
- 换电脑：拷贝整个数据根目录，在新电脑上装好 skill 后运行 `install.py --root <新位置>`。

## 后台服务
- 只监听本机 127.0.0.1，内存约 10–20 MB，平时 CPU 为 0，没有窗口。
- 停止并取消自启：运行 `engine/uninstall.py`（不删除任何报告和笔记）。恢复：重新运行 skill 里的 `engine/install.py`。
